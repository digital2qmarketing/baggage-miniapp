# БАГГАЖ — Mini App заказа доставки

Статическая страница формы заказа для Telegram-бота БАГГАЖ. Собирается из основного репозитория бота (`npm run miniapp:build`), сюда выкладывается только готовый результат.

Здесь нет секретов и данных клиентов: заявка уходит боту через Telegram (`WebApp.sendData`), цену бот пересчитывает сам.
